# Bicker

Interactive online debate platform where users can challenge ideas, argue positions, and engage in structured discussions.

---

## Overview

Bicker is a web application designed to make debating fun, structured, and competitive.

Users can:
- Start debates  
- Respond to arguments  
- Evaluate different perspectives  
- Engage in interactive discussion formats  

The platform is built around the idea that debating should be **accessible, engaging, and dynamic**, not limited to formal settings.

---

## Features

-  **Instigate Mode** – Start a debate with a prompt or opinion  
-  **Debate Mode** – Respond and argue against others  
-  **Deliberate Mode** – Review and compare both sides  
-  **Gamified Experience** – Encourages engagement and participation  
-  **User Profiles** – Track activity and contributions
